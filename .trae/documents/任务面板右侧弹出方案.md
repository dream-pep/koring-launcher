# 任务面板：Windows 通知中心式右侧弹出

## Summary

参考 Windows 通知中心，新增一个**从右侧滑出的任务面板**：点击顶栏任务按钮即可打开，无遮罩、点击外部关闭，任务进度实时更新。

按用户确认：
- **旧 `task-queue` 页面与路由保留不动**（仅修改顶栏按钮逻辑）
- **无遮罩**，点击面板外部区域关闭

## Proposed Changes

### 1. 新建面板开关 store — `src/stores/taskPanelStore.ts`

轻量 zustand：

```ts
interface TaskPanelState {
  open: boolean;
  openPanel: () => void;
  closePanel: () => void;
  togglePanel: () => void;
}
```

（职责单一，不并入 taskStore）

### 2. 新建任务面板 — `src/components/task/TaskPanel.tsx`

**结构与内容**（复用现有视觉语言）：

- 固定定位：`fixed right-0 top-[40px] bottom-0 w-[380px] z-[90]`
  - `top-[40px]` 避开标题栏；`z-[90]` 位于内容区（z-[1]）之上、标题栏（z-[100]）之下，不遮挡窗口控制按钮
- 视觉：`bg-background/95 backdrop-blur-xl border-l border-border/40 shadow-2xl`（Windows 通知中心式玻璃侧栏）
- 头部：标题「任务」+ 进行中数量徽标 + 右侧「清空历史」（有已完成任务时显示）+ 关闭按钮（X）
- 内容区 `flex-1 overflow-y-auto`：
  - 分组：进行中 / 已暂停 / 已完成（与 task-queue 页一致的小标题样式）
  - 条目：`<TaskCard task={t} />`（复用，不改）
  - 空状态：`Inbox` 图标 + 「暂无任务」
- 动画：`mounted + visible` 双状态 —— 打开时 `requestAnimationFrame` 置 `translate-x-0`，关闭时先 `translate-x-full` 再 220ms 后卸载；过渡 `duration-[220ms] ease-spring-soft`（与项目其它浮层一致）
- 关闭交互：
  - 点击面板外部：`document` 上 `pointerdown` 监听，`!panelRef.contains(target)` 且 target 不在 `[data-task-panel-trigger]` 内 → `closePanel()`
  - `Escape` 键关闭
  - 面板内部点击不关闭

### 3. 修改顶栏任务按钮 — `src/components/task/TaskButton.tsx`

- `onClick`：`navigate("task-queue")` → `togglePanel()`（来自 `taskPanelStore`）
- 保留原有运行中旋转 / 暂停图标逻辑
- 按钮加 `data-task-panel-trigger` 属性（供面板外部点击检测排除自身，避免「点开即被外部关闭逻辑关掉」的竞态）

### 4. 挂载面板 — `src/layouts/RootLayout.tsx`

在 `<ConfirmDialog />` 附近（内容区与 SystemLayer 之后）挂载 `<TaskPanel />`，保证所有页面都能显示面板。

### 5. 明确不改动

- `src/pages/task-queue.tsx` 页面文件不删、不改
- `routeStore.ts` 的 `task-queue` 路由与 `App.tsx` 的页面注册不动
- `task-debug.tsx` 的「打开任务队列」按钮维持 `navigate("task-queue")`（旧页面仍可访问）
- `TaskCard.tsx`、`taskStore.ts` 不改

## Assumptions & Decisions

1. **面板宽度固定 380px**（Windows 通知中心占比），高度从标题栏下沿到底部
2. **无遮罩**，背景保持完整可见；点击外部或 Esc 关闭
3. **z-index 取 90**：高于内容、低于标题栏，避免遮挡窗口控制与顶部导航
4. 面板状态独立于路由 —— 切换页面时面板保持打开（全局浮层语义），符合通知中心习惯
5. 旧页面保留，作为兼容入口（调试页仍可跳转）
6. 圆角：面板右侧贴边、不设圆角（与 Windows 通知中心一致），仅左侧描边分隔

   - 旧入口仍可用：调试页「打开任务队列」→ 进入原独立页面
